# বাংলাদেশ সাইন্স সেমিনার সিম্পোজিয়াম (BSSS)

বাংলাদেশ সাইন্স সেমিনার সিম্পোজিয়াম ফাউন্ডেশনের অফিসিয়াল ওয়েবসাইট।

## ফিচারসমূহ

- 🏠 আকর্ষণীয় হোম পেজ
- 📖 আমাদের সম্পর্কে সেকশন
- 👥 কর্মকর্তাবৃন্দ (প্রেসিডেন্টসহ) — অ্যাডমিন থেকে নতুন কর্মকর্তা যোগ/মুছে ফেলা যায়
- 🖼️ গ্যালারি
- 📚 প্রকাশনা
- 📢 নোটিশ বোর্ড — অ্যাডমিন থেকে নতুন নোটিশ যোগ করা যায়
- 🔐 লগইন / সাইন আপ সিস্টেম (localStorage ভিত্তিক)
- 📱 সম্পূর্ণ রেসপন্সিভ ডিজাইন

## অ্যাডমিন অ্যাক্সেস

```
ইমেইল: admin@bsss.org
পাসওয়ার্ড: admin123
```

অ্যাডমিন হিসেবে লগইন করলে কর্মকর্তা ও নোটিশ যোগ করার প্যানেল দেখা যাবে।

## কীভাবে ব্যবহার করবেন

1. সব ফাইল একই ফোল্ডারে রাখুন
2. `index.html` ফাইল ব্রাউজারে ওপেন করুন
3. অথবা GitHub Pages এ ডিপ্লয় করুন

## GitHub Pages এ ডিপ্লয়

1. নতুন GitHub রিপোজিটরি তৈরি করুন
2. সব ফাইল আপলোড করুন
3. Settings → Pages → Source: main branch → Save
4. কয়েক মিনিট পর আপনার সাইট লাইভ হবে

## ফাইল স্ট্রাকচার

```
bsss-website/
├── index.html      # মূল পেজ
├── styles.css      # স্টাইলশিট
├── script.js       # জাভাস্ক্রিপ্ট
├── president.png   # প্রেসিডেন্টের ছবি
└── README.md
```
